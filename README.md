# 音声書き起こしアプリ

このアプリケーションは、音声ファイルをアップロードすると自動的に書き起こします。

## 技術

- Docker
- Docker Compose
- python
- Streamlit

## 使用方法

```bash
docker-compose up --build
```

## アプリケーションの使用

- ブラウザで http://localhost:8501 にアクセス
- 音声ファイル（WAVまたはMP3形式）をアップロード
- 処理が完了すると、話者ごとに分けられた書き起こし結果が表示されます

## 機能

- 音声の自動書き起こし（Whisperモデル使用）
- 日本語を含む多言語対応
- WAVおよびMP3形式のファイルに対応

## 注意事項

- 処理時間は音声ファイルの長さによって変わります
- 話者分離の精度は低いです

## 最後に

- このアプリはCursorでベースを自動で作成してます。
- CPUで動かすためlargeモデルを利用しておらず、精度がすごく悪いです。
　GPUなどを搭載し、largeモデルで動かせばましになると思います。
