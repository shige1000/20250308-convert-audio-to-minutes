# 音声書き起こしアプリケーション

## 概要

このアプリケーションは、音声ファイルをアップロードすると自動的に書き起こしを行うWebアプリケーションです。

### 特徴
- 音声の自動書き起こし（Whisperモデル使用）
- 日本語を含む多言語対応
- WAVおよびMP3形式のファイルに対応

### 開発背景
- Cursorエディタの機能を実感するため、このアプリケーションはほとんどAIによって作成されています
- CPUで動作するため、largeモデルを利用しておらず、精度は限定的です
- GPUを搭載してlargeモデルを使用すれば、より高い精度が期待できます

## 技術スタック

- Docker
- Docker Compose
- Python

## セットアップ・使用方法

### アプリケーションの起動

```bash
docker-compose up --build
```

### アプリケーションの使用

- ブラウザで http://localhost:8501 にアクセス
- 音声ファイル（WAVまたはMP3形式）をアップロード
- 処理が完了すると、話者ごとに分けられた書き起こし結果が表示されます

## 注意事項

- 処理時間は音声ファイルの長さによって変わります
- 話者分離の精度は限定的です
- CPUでの処理のため、大きなファイルの処理には非常に時間がかかります
